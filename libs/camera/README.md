# Camera Tools

Fly the camera around, or orbit it round a point.

| Key | Does |
| --- | --- |
| F6 | Turn it on and off |
| WASD, Q, E | Move, down, up |
| Right mouse | Look around |
| O | Switch between flying and orbiting |
| Shift, Ctrl | Faster, slower |
| Mouse wheel | Speed, or distance when orbiting |
| Z, C, X | Roll, and level |
| H | Hide the controls |

Change any of them, and turn on a controller, in Settings.

Needs a plugin for your game that supports it. For those, see `schemas/camera.sal`.
