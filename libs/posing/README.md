# Posing

Pick a character and a bone, then turn, move or scale it with the gizmo or the boxes.

| Key | Does |
| --- | --- |
| F7 | Open Posing |
| F8 | Freeze the character |
| Keypad . | Orbit the camera round the bone |

Needs a plugin for your game that supports it. For those, see `schemas/posing.sal`.
