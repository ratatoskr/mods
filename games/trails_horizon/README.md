# Trails beyond the Horizon

For The Legend of Heroes: Trails beyond the Horizon (Kai no Kiseki), on Steam and GOG.

- Wraith's free camera moves the game's camera.
- Wraith's posing works for the characters in the game.
- Wraith's game speed controls how fast the game runs, allowing you to speed it up, slow it down, or pause it.
- Tweaks:
  - **Money & points**: change Mira, Sepith and gourmet points, and see play time.
  - **Script Variables**: change SP, which the game keeps in its script variables.
  - **Free shopping**: buying costs nothing.
  - **Give Mira**: adds Mira, 10,000 by default.
  - **Spawn item**: gives you any item, picked from the game's item list by name.
