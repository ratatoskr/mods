# Granblue Fantasy: Relink

For Granblue Fantasy: Relink.

- Wraith's free camera moves whichever of the game's cameras is on screen, in the field, in battle, in Photo mode and in cutscenes.
- Wraith's posing works for every model with a skeleton: characters, monsters, weapons and props. Bones are named for the game's joint numbers, like `_00a`.
- Wraith's game speed controls how fast the world runs, allowing you to speed it up, slow it down, or pause it. The game's own slow motion, like hit stop, still plays on top.
- Other plugins' `threads.onTick` runs on the game's own thread.
